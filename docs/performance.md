# 扫描与页面加载

## 虚拟媒体库浏览

虚拟库的电影、整部剧列表在明确作品类型且映射全为作品时直接查询原 Emby ID，避免因为客户端的 `Recursive=true` 先遍历全部季和分集。题材、年份等作品筛选复用该查询范围，NextUp 直接查询真实父项；季、分集、Latest/Resume、完整分集计数及旧文件夹容器继续保留原范围。该优化减少上游请求数量，不缓存完整媒体列表。

身份恢复检查按虚拟库、上游、用户、认证凭据和映射快照缓存 30 秒；无关分页、筛选和展示请求头不影响复用，同一上下文的并发检查合并。失败和取消不记作成功，映射变动触发重新检查；实际浏览查询仍每次使用原客户端凭据，缓存不替代上游鉴权。具体边界见 [虚拟媒体库](virtual-libraries.md)。

本地现有两部剧的同参数递归作品列表，优化前连续三轮 HTTP 耗时为 4173、5501、3046 ms，优化后为 189、137、90 ms，返回条目 ID 与数量一致；优化后作品筛选请求为 84 ms。这些数值只包含接口请求，不含浏览器绘制与海报下载，上游负载也会影响实际耗时。真实季、分集请求的状态、数量及条目身份与直连上游对照一致。

## 扫描执行

后台全库扫描只执行一轮。定时轮询复用正在执行的扫描；多个显式强制触发合并成至多一轮后续扫描，不并发起扫。完整扫描失败后，自动扫描依次退避 1、2、4、8、16、30 分钟，成功后恢复配置周期。相同库根的手动与后台请求共用一次扫描及其结果，失败也会传给每个调用方。

生产启动器将数据库路径传给媒体库服务。匹配、库存差量写入与已存进度更新在一个 worker 线程中执行；内存数据库及未配置 worker 的测试用法保持同步。worker 直接打开已经迁移的 SQLite 文件，不运行迁移或数据库对账。

扫描事务使用立即写事务，避免读取快照后被其他连接写入而无法升级写锁。库存条目仅在字段变化时更新；分集身份未变化时保留行、主键和创建时间。相同作品的标题匹配结果（包括未匹配结果）在一轮内复用。每轮仍记录扫描历史、库根状态及任务检查时间。

生产日志使用独立的零等待数据库连接。写锁繁忙时最多缓冲 1,000 条，按批重试，不在 HTTP 请求结束时等待写锁；清理使用同一连接。缓冲溢出或退出时仍无法写入，会向标准错误报告丢弃数量。数据库业务写操作仍受 SQLite 单写者限制，worker 并不消除磁盘或锁竞争。

### 库存完整性

Emby 作品与分集通过分页读取，校验总数、页偏移、唯一条目 ID 和必要字段。任何一页失败、总数变化、提前空页或异常条目都会让整轮失败，保留原库存，不将部分结果发布为完整扫描。Emby 必须返回有效的 `TotalRecordCount`；无法证明完整时扫描失败并留下错误。

生产扫描器只有在作品与分集都读取成功后才返回 `{ items, complete: true }`。自定义扫描器返回旧数组格式仍可更新已见记录，但不会清除未见记录；明确的不完整批次会拒绝写入。完整空扫描也保留已有非空库存，避免瞬时空响应造成清空；确认清空仍需独立操作。

### 缺集元数据

文件数据库的缺集检测在只读 worker 中准备分集集合、来源标题、候选作品与旧快照。每轮用一个读取事务取得一致数据，随后释放事务并按作品传回数据，避免一次向主线程传输全部分集。检测结束或失败关闭 worker；读取失败先等待已开始的检测完成，再结束本轮，并跳过快照清理，避免与下一轮重叠。缺集算法和候选范围保持原有规则；内存数据库与没有打包 worker 的源码运行路径直接读取。

隔离副本包含 204,848 条分集记录。本机单次测量中，原分集与来源标题准备阶段造成主事件循环最大延迟约 413 ms；改后 worker 初始化约 746 ms，分批读取全部作品约 302 ms，整个阶段主事件循环最大延迟约 14 ms。逐项对账 4,360 个候选作品、178,117 个去重分集及来源标题、旧快照完全一致。该优化减少主线程阻塞，初始化仍需等待；测量不包含 TMDB、Emby 请求或完整缺集检测耗时。

TMDB 请求默认 15 秒截止，覆盖连接和 JSON 正文读取。缺集检测按季保留缓存，完整成功的缓存有效期为 12 小时。某季失败保留该季旧缓存和上一轮完整缺集展示，不把部分成功时间记为完整刷新时间。首次检测不完整时只保存失败诊断，不生成“缺集为零”的快照；页面提示检测不完整。

失败诊断、成功季缓存和重试时间保存在 SQLite 的内部设置中，重启后继续生效，不通过配置接口暴露或修改。失败后至少等待 5 分钟才能重试，恢复时复用仍有效的成功季。5 分钟是最早允许重试的时间，自动检测仍遵循配置周期，默认每小时。

缺集页面按选中启用库的本地库存与共享 TMDB 缓存重算，不等待 Emby `System/Info`。用于网页跳转的服务器 ID 在后台读取，成功缓存 10 分钟，失败 30 秒后允许重试并保留已有 ID；首次读取时 ID 可以为空。Emby 地址或凭据改变后旧连接缓存失效。

文件数据库的按库缺集查询在独立只读 worker 中执行，通过同一事务读取启用状态、当前库库存与元数据，避免大库重算阻塞 HTTP 主线程。worker 不执行迁移、不修改业务数据、不缓存已完成结果；仅合并相同库、参数及数据库变化版本的在途读取。空闲 30 秒释放、异常后重建，单次读取截止时间为 30 秒；服务关闭时先终止 worker 再关闭数据库。内存数据库与缺少构建产物的源码运行回退直接读取，部署需包含 `missing-root-worker.mjs`。

## 管理页面

其他管理页不会预载整个媒体库。媒体库页先读取概览，再加载选中的一个库，每页 48 个作品；筛选、排序与分页由服务端执行。卡片只携带一个代表条目与真实文件数，打开详情才读取该作品的完整分集。

作品在同一库内优先按媒体类型与有效 TMDB ID 归组；没有 TMDB ID 的按片名、年份与类型归组。详情使用与卡片一致的身份筛选，保留同作品的别名与年份差异，不跨库读取，不把同名但不同 TMDB ID 的条目混入。该规则不重写库存或扫描数据。

接口：

- `GET /api/library/summary`：当前库根、汇总和未匹配诊断。
- `GET /api/library/roots/:rootId/works`：作品页；支持 `page`、`pageSize`（最大 100）、`q`、`type`、`status`、`year`、`resolution`、`codec`、`genre`、`sort`。
- `GET /api/library/roots/:rootId/works/items?key=…`：当前库内作品详情。
- `POST /api/library/roots/:rootId/scan`：返回库根和发现数量，页面随后刷新概览及当前页。兼容的完整库存接口仍保留。

概览缓存以库根扫描状态与更新时间判定失效，最长 60 秒；手动扫描、补齐和绑定也显式失效。外部直接修改 SQLite 的元数据可能等待缓存过期后才显示。

任务列表先展示 API 返回的任务与已有海报，再异步补齐缺少的海报；补图最多并发 3 个请求，相同作品共享请求和缓存，超时或失败不阻挡任务列表。旧页面请求的结果不能覆盖较新的列表。

页面 JSON 请求的截止时间覆盖响应正文。普通列表默认 15 秒，海报 8 秒，手动扫描与批量补齐 180 秒。切换库或筛选会取消上一页请求。前端日志每批 10 条，失败从 5 秒退避至最多 60 秒，待发队列最多 200 条；新增日志不会绕过失败退避。

管理端登录、退出与登录锁定查询也有 15 秒截止；锁定查询包含正文读取，失败会结束遮罩并提示连接问题。退出立即清理本地任务和门户状态，新登录等待当前退出请求结束再发送，避免正常响应中的会话 Cookie 操作乱序。身份切换与组件销毁使旧鉴权结果失效；取消不能撤销服务端已签发的 Cookie，退出失败会提示刷新后可能仍保持登录。

任务创建与改绑 TMDB 的前端等待为 180 秒，其他任务操作及映射读取为 15 秒，截止时间包含需要消费的成功与错误正文。任务操作使用独立身份轮次：普通列表刷新不取消写操作，退出、重新登录、鉴权失效或服务 scope 销毁会取消旧等待；迟到的 401 不清除新登录，迟到成功也不刷新新身份的列表。不同任务操作可以并行。写入超时只代表结果未确认，页面提示刷新检查后再重试，不自动重发。

任务抽屉的 TMDB 搜索和分季查询为 15 秒完整正文截止，同类新请求取消旧请求，两类查询互不取消。关闭、重开抽屉或组件销毁会取消搜索，并通过抽屉轮次屏蔽旧结果、错误和忙状态；创建、改绑、删除失败会恢复按钮且不产生未处理拒绝。关闭抽屉不撤销已经发出的服务端写操作。

系统状态、连接状态、配置与卡密读取有 15 秒完整正文截止；重复读取取消旧请求，页面退出或身份失效后，旧响应、401 与加载状态不再影响当前页面。配置保存保留 90 秒等待，改口令为 15 秒；保存和改口令互斥，旧读取不覆盖保存结果，保存失败保留表单草稿。Emby 连接测试为 30 秒，邮件测试为 90 秒，在途测试合并并禁用相应按钮；邮件超时仍可能已经发送，不自动重试。

卡密生成、修改、删除为 15 秒，AI 文案为 125 秒，覆盖服务端可配置的最长 120 秒及响应余量。逐行删除仍可并发，静默刷新过滤在途删除行，失败仅恢复本次目标，避免整份旧列表覆盖其他删除结果。离开页面取消等待，旧 AI 文案不填入后来选择的卡密。写操作超时或取消不代表服务端未执行，需刷新核对实际结果。

离开管理端媒体库页会取消概览、分页、详情、扫描与补齐请求的前端等待，重新进入可正常加载；关闭或切换详情取消旧详情。旧响应、错误、401 和加载状态不能影响后来的请求，组件销毁后不再发起读取。取消与超时不回滚服务端已经开始的扫描或补齐操作。

门户详情请求按选中作品身份启动，空简介不会触发循环请求；切换作品会取消旧请求，旧响应不会覆盖新选择。最近入库独立展示，不等待热榜成功。总览路由通过页面包装器传入鉴权与导航服务。

门户影视库的搜索、最近入库、列表、库存详情与 TMDB 补充请求均使用 15 秒完整正文截止时间；坏 JSON 作为可处理失败返回。切换作品、筛选或离开页面会取消请求，旧响应不会覆盖新页面。会员使用记录只应用最新范围和会员的结果；关闭详情立即取消读取并退出加载，后台刷新完成不覆盖用户后来选择的范围。

会员资料读取默认 15 秒截止；登录、开通、验证码及账号修改等请求为 90 秒，均包含成功和错误响应正文读取。退出或身份切换立即使旧请求失效，旧资料不能恢复登录状态，旧权限拒绝不能清除新身份。超时只结束前端等待，不代表已经开始的服务端写操作被回滚。

Emby 用户列表读取为 15 秒，在线会话读取为 30 秒，账号与会话写操作为 90 秒，均包含响应正文。相同账号的写操作互斥，不同账号可并行；写完成再次取消在途旧列表，避免迟到刷新恢复已删除账号或覆盖启停状态。离开页面取消前端等待，旧响应不能改写页面或触发登录提示，创建和改密成功不会清除等待期间的新草稿。

并发策略读取与保存均为 15 秒。保存不重复提交，不自动重试；旧读取不能覆盖新草稿或保存状态，保存响应也不覆盖等待期间的新编辑。离开页面取消等待，当前登录失效会进入管理端登录处理。写操作超时或取消不代表服务端没有执行，需重新读取确认结果；账号、冻结与解冻规则保持不变。

## 门户影视库

影视库列表使用作品级轻量索引筛选、排序与分页，只读取当前页作品的完整元数据和库存。中文标题排序、全局筛选面板、未匹配分组与旧详情 ID 的兼容规则保留；详情直接按目标查询，不构建全库索引。

当前库存统计、门户列表/筛选/搜索/最近入库/详情/在库判断及热榜“可看”标记只使用启用媒体库。同一作品跨启用库与停用库时，文件数与库存标签只计算启用库。同步配置发现媒体库消失时只将库根停用，不再自动清除旧库存。停用库的库存、分集、元数据及扫描历史保留；重新启用后恢复参与查询。此规则不自动改变已保存的任务进度或缺集快照，也不删除历史数据。

生产构建包含独立的只读列表 worker。索引构建、缓存校验、SQL 临时索引及当页读取都在后台线程完成，HTTP 主线程仅传递查询条件和当页结果。worker 不执行迁移，不修改持久业务数据；空闲时不阻止进程退出，关闭服务时终止。内存数据库及未构建 worker 的源码运行仍使用同步路径。

索引通过数据库变化版本及相关字段指纹校验，避免无关日志或使用记录变化触发全库重建；普通库存变化检查间隔至少 1 秒。每次读取单独检查库根 ID 与启用状态，停用、重新启用不等待该间隔，即使库根更新时间没有改变也会刷新索引、总数与筛选面板。库存、分组身份、标题、年份、标签与筛选字段变化后重建，详情始终直接读取当前数据。临时表只存在于 worker 连接；显式禁止临时写入的连接使用 JSON 查询兼容路径。

隔离数据库副本保留全部 222,235 条库存，当前展示使用 26 个启用库的 63,262 条库存，共 7,102 个作品；50 个停用库的 158,973 条库存未删除。本机单次测量：首次列表含 worker 启动约 749 ms，主事件循环最大延迟约 10 ms；随后五次分页约 9–18 ms，目标详情约 3 ms。每页 24 个作品，首次响应 101,670 字节。首次索引仍有初始化开销，后续库存变化的校验也有成本；这些测量不代表生产网络延迟。

## 热榜与图片请求

热榜接口先返回进程内的本地快照，不等待外部榜单或 Redis。没有快照时返回空列表及 `refreshing` 状态，后台按来源合并刷新请求；门户在刷新期间每 5 秒检查一次结果，离开页面会取消请求与轮询。已有内容在更新或网络失败期间继续展示。每个来源的刷新总截止时间为 60 秒，包含分页和正文读取，同时保留适配器自身的较短请求截止时间。

刷新失败保留旧快照，重试至少等待 30 秒，连续失败逐步退避至 15 分钟；这是最早允许重试的时间，实际重试由后续读取或后台定时器触发。禁用来源后，其旧快照和未完成的刷新不会重新出现在接口结果中。

图片代理的截止时间覆盖下载正文：外部图片 8 秒、Emby 图片 15 秒，单张最多 10 MiB，并校验图片 MIME 类型。非成功响应、异常、超限、超时和客户端断开都会取消下载并释放未消费正文；重定向逐次检查允许地址，Emby 图片只允许同源跳转。外部图片失败返回不缓存的占位图，Emby 图片失败仍返回原有错误响应。

## 会员操作与后台任务

重复使用已兑换卡密只返回现有会员信息及会话，不重新续期、恢复账号或发送邮件；会员已删除时不凭旧卡重建。过期会员只可查看资料和续费，管理员停用同时阻止新登录与旧会话；续费不能解除并发冻结。服务端动态校验会员状态，内容接口与 Emby 恢复入口使用一致规则，详见 [会员访问与账号恢复](member-access.md)。

并发播放检查复用管理员豁免身份缓存，避免每轮重新获取管理员列表；默认限制变更立即生效，Emby 地址或凭据变更会清除身份缓存。此修改不改变冻结和解冻规则。

后台并发超限升级检查每 10 秒触发，但同一运行时只允许一轮执行。Emby 请求或邮件投递较慢时跳过重叠触发，不排队补跑；成功或失败后释放运行标志，下一次定时触发可继续执行。运行时停止后不启动新轮，已经开始的账号处理按原逻辑完成。累计时长封顶、提醒阈值、冻结时长和账号恢复规则保持不变。

活动日志同步与 Emby 会员自动绑定保留启动执行及每 10 分钟检查，同一任务上一轮未结束时跳过，不排队；完成或失败后允许下一周期执行。后台与手动调用在同一应用数据库连接内共享在途结果，不同连接互不合并；本轮使用首先发起调用的参数。运行时停止后不启动新轮，已开始的业务处理继续按原规则完成。活动日志接口不支持时仍只警告一次，会员绑定、有效期和历史身份修复规则保持不变。

活动日志标题补充只读取本轮涉及的 Emby 条目，每批最多 500 个 ID；没有相关条目时不查询库存。仍允许读取停用库的历史标题，不改变使用记录的历史归属。隔离副本单次测量：100 个目标条目的标题与原全库映射逐项一致，原实现加载 222,235 行约 794 ms，当前实现返回 100 个标题约 78 ms。SQL 仍有筛选成本，未新增索引；该样本不代表生产请求耗时或整个同步周期耗时。

管理端会话媒体流补充按连接身份隔离缓存，同一条目共享在途请求，每个连接最多并发 4 条。列表在取得基础会话后最多等待 2 秒补充详情，预算到即返回基本信息与已完成详情；慢请求后台完成后供下次读取使用，上游自身 15 秒截止时间不变。成功缓存 10 分钟，失败缓存 30 秒，最多保留 1,000 条；动态切换 Emby 地址或凭据后，旧结果不会用于新连接。运行时停止后，看门狗的迟到成功或失败不会重新创建定时器；重复停止幂等。

会员到期提醒在邮件成功发送后才记录提醒状态，投递失败或未配置邮件会在下一轮检查重试，自动检查间隔为 6 小时。明确关闭邮件偏好的会员仍按现有语义标记为已处理。重叠检查合并；发送过程中续费、停用或相关状态改变，不写入旧提醒标记。SMTP 成功和数据库写入不是同一事务，两者之间进程退出仍可能导致重复提醒。

修改后扫描数据取 worker 初始化和一次匹配规范化后的重复扫描，验证未变化库存的稳定路径；首次启动和真实 Emby 拉取另有开销。

验证覆盖还包括 Emby 分页异常与不完整扫描保护、worker 完整性标志传递、缺集失败缓存跨重启恢复、TMDB 异常元数据保护、HTTP 上游无响应、旧卡只读重放、管理员缓存复用、会员提醒失败与并发状态变化、门户详情切换、会员动态权限与恢复竞态，以及跨库删除隔离、缓存失效和配置变化保护。门户列表还覆盖真实文件数据库 worker、跨连接缓存校验、崩溃重建与关闭清理；热榜覆盖旧快照优先、失败退避、来源禁用和总截止时间；图片覆盖正文失败、超限、重定向及取消清理。后端 124 个文件、808 项测试，前端 62 个文件、371 项测试全部通过；`pnpm typecheck`、`pnpm build` 和本批修改文件的 ESLint 检查通过。未执行生产部署或真实 Emby 的写操作。

缺集查询和删除统一使用公开 `rootId`，即上游 Emby 库 ID；数字和 GUID 都精确解析，不回退到本地库根行号。查询按所选启用库的索引库存与 TMDB 缓存独立重算，不因浏览页面发出 TMDB 请求，停用库及其他库副本不参与结果。历史快照和库存保留；后台进度仍反映共享作品元数据刷新。

删除前完整读取所选库真实条目与分集，按合并集范围和集名保护重新核对；不凭全局历史快照授权删除。无完整元数据、读取失败或没有实际缺集时不删。读取后与每次删除前复查库、作品身份和连接，变化即停止。其他库库存与副本保留，当前库汇总缓存失效；最后一份库存删除后才清共享快照。部分远端删除失败会报告失败并审计已删除条目，待扫描对账。

独立浏览器深度流程以编译后的应用和临时 SQLite 验证当前页面与实际 HTTP 接口，11 项通过，覆盖登录、任务幂等创建、Emby 库存扫描、设置脱敏、退出后的用途隔离、慢读取时切页和退出、任务抽屉重开后的旧搜索隔离以及移动端导航。Emby 与 TMDB 使用本地上游夹具，其他外网请求被拒绝；不代表真实上游或生产代理已经验证。深度检查阶段 Docker 冒烟的构建、健康、登录、重建持久化、四个入口和容器文件系统检查通过；之后的前端请求保护补充修复验证了应用构建和浏览器流程，未重复构建容器镜像。运行命令与隔离范围见 [测试说明](../tests/README.md)。

未完成的 API 响应关闭时记录一次 `request_aborted`，状态留空，并记录方法、路径与耗时；正常结束及断连后的迟到结束不重复记录。用户切页、前端超时或代理断开都可能产生该事件，不能单凭它确定根因。7 项真实 HTTP 回归验证断连、防重复及日志排除边界。代理时长日志、等待预算与直连/公网健康对照见 [运行故障排查](runtime-diagnostics.md)；这些文档示例尚未应用到生产代理。

停机首次信号立即停止后台调度，再排空 HTTP、关闭列表与扫描 worker、日志连接，最后在同一事件循环回合关闭数据库并退出。收尾统一预算 25 秒；超时、清理失败、第二次退出信号均退出 1，正常收尾退出 0。Compose 提供 30 秒停止宽限；应用计时器不能抢占同步主线程阻塞，不保证所有在途后台业务完成，也不回滚远端写入。

未捕获同步异常和未处理 Promise 拒绝按用户确认的策略记录后退出 1，不再继续提供服务。同步应急日志只包含固定事件与退出码，正常错误日志脱敏且限长；记录器或同步日志清理失败不阻止退出。17 项新增回归覆盖真实 HTTP 排空、卡死与清理失败、重复信号，以及独立子进程的异常、Promise 拒绝和日志故障退出。容器自动重启尚未实测；本地启动需外部服务管理器。

扫描历史暂不增加自动删除策略。实际生产断连与代理超时还需结合运行日志验证，不能仅凭本地回归认定全部消失。

请求回归还覆盖门户坏 JSON、成功与错误正文挂起、退出后的迟到资料与权限拒绝、使用记录切换和关闭竞态；Emby 回归覆盖跨连接缓存、限流单飞、2 秒补流预算、策略读取失败禁止写入及停止后的迟到看门狗请求。

缺集数据准备回归覆盖真实文件数据库 worker、零号与绝对集号、单轮一致快照、关闭与初始化失败，以及读取失败期间在途检测完成前禁止启动下一轮。

并发升级调度回归通过实际运行时验证慢请求跨三个定时触发仍只执行一轮、失败后下一周期恢复，以及停止后迟到成功或失败不会启动新轮。

管理端生命周期回归覆盖登录和退出超时、锁定响应正文挂起、旧登录和锁定响应、退出与新登录排序、重复退出取消排队登录、scope 停止后禁止请求和轮询，以及媒体库概览、详情、扫描、补齐在页面退出后的取消和迟到结果隔离。

其余管理页回归覆盖系统与连接查询的慢正文、旧鉴权拒绝与取消后重进、测试单轮执行、配置保存与读取交错、失败保留草稿、卡密并发删除的两种完成顺序，以及离页后的写操作和 AI 回调隔离。Emby 用户管理还覆盖同账号写互斥、不同账号并行、删除期间刷新迟到隔离、90 秒写等待与退出取消；并发策略覆盖慢正文、保存与草稿编辑交错、卸载及当前鉴权拒绝的页面接入。

后台同步回归覆盖跨多个周期的慢任务、失败恢复、停止后的迟到成功和失败、接口不支持只警告一次、手动与后台请求合并及不同数据库连接隔离；标题查询覆盖空日志不读库存、跨历史库标题兼容及超过单批大小的目标查询。
